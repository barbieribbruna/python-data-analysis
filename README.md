# Python Data Analysis

Projeto de estudo e prática em análise de dados utilizando Python, SQL e bibliotecas de Data Analysis.

O projeto foi desenvolvido em Google Colab e posteriormente estruturado para portfólio no GitHub.

---

## Objetivo

Este projeto tem como objetivo praticar:

- manipulação e tratamento de dados;
- consultas SQL com SQLite;
- integração entre SQL e Pandas;
- análise exploratória de dados;
- criação de gráficos e visualizações.

---

## Tecnologias e bibliotecas utilizadas

- Python
- Pandas
- NumPy
- Matplotlib
- SciPy
- Seaborn
- Plotly
- Jupyter Notebook
- VSCode

---

---

## Etapas do projeto

### Análise de dados

No notebook `analise_dados_python.ipynb` foram realizados:

- leitura de bases de dados;
- tratamento e limpeza de dados;
- renomeação de colunas;
- merge entre DataFrames;
- consultas SQL;
- cálculo de correlação;
- criação de base tratada.

---

### Visualização de dados

No notebook `visualizacao_dados.ipynb` foram desenvolvidos:

- gráficos de barras;
- gráficos de linha;
- gráficos de dispersão;
- visualizações interativas com Plotly.

## Como executar o projeto

### 1. Clone o repositório

```bash
git clone https://github.com/barbieribbruna/python-data-analysis.git
```

---

### 2. Acesse a pasta do projeto

```bash
cd python-data-analysis
```

---

### 3. Instale as dependências

```bash
pip install -r requirements.txt
```

---

### 4. Execute o notebook

Abra o arquivo `.ipynb` utilizando:

- VSCode
- Jupyter Notebook
- Google Colab
